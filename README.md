# AI-Based Semiconductor Device Characterization and Analysis

## Overview

An independent computational physics project focused on semiconductor device simulation, electrical characterization, and machine learning-based anomaly detection.

The project explores the electrical behavior of PN junction diodes and MOSFETs using Python-based mathematical models.

## Objectives

- Simulate PN junction diode I-V characteristics
- Model MOSFET output characteristics
- Investigate temperature-dependent semiconductor behavior
- Generate and analyze synthetic semiconductor datasets
- Explore machine learning for anomaly detection
- Apply computational physics and scientific data analysis

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab
- Jupyter Notebook

## Project Modules

### 1. PN Junction Diode Simulation
Simulation of current-voltage characteristics using the Shockley diode equation.

### 2. MOSFET Simulation
Modeling drain current as a function of gate voltage and drain voltage using a simplified square-law model.

### 3. Semiconductor Data Analysis
Generation and visualization of synthetic semiconductor electrical measurements.

### 4. AI Anomaly Detection
Exploration of Isolation Forest for identifying unusual device characteristics in synthetic datasets.

## Limitations

The current project uses simplified mathematical models and synthetic data. The results are not experimental measurements of commercial semiconductor devices.

## Academic Context

Independent project developed alongside the International Physics Studies Program (IPSP) at Leipzig University.
